# 💰 Personal Finance Tracker (Database-Free Version)

A lightweight, full-stack **Personal Finance & Expense Tracker** web application built with **Python (Flask)**, **JSON Data Persistence**, **HTML5**, **CSS3 (Glassmorphic Dark Mode)**, and **JavaScript (ES6+)**.

This version is completely **database-free**—it uses lightweight JSON data storage and in-memory structures, making it zero-configuration, super fast, and easy to deploy on any machine without database setups!

---

## 🌟 Key Features

- 📊 **Interactive Dashboard**: Real-time Net Balance, Total Income, Total Expense, and Savings Rate calculations.
- 📈 **Data Visualization**: Dynamic Chart.js charts showing spending by category (Doughnut chart) and monthly cashflow trends (Bar chart).
- 💸 **Transaction Management**: Full CRUD capabilities with real-time text search, type filtering, and category filtering.
- 🎯 **Budgeting & Goals**: Set category spending limits with progress indicators (alerts when approaching or exceeding limits).
- 📄 **CSV Data Export**: Stream and download transaction history as standard `.csv` files.
- 🚀 **Database-Free Architecture**: Operates on structured JSON file storage (`finance_data.json`) with zero SQL or database overhead.
- 💎 **Modern Glassmorphic UI**: Responsive dark mode design system with smooth CSS micro-interactions and modal dialogs.
- 🎲 **Sample Data Generator**: Built-in reset button to populate sample transactions for quick demo testing.

---

## 🛠️ Tech Stack & Technologies Used

- **Backend**: Python 3, Flask (RESTful API), JSON File Handling
- **Frontend**: HTML5, Vanilla CSS3 (Custom Variables, Flexbox, CSS Grid, Glassmorphic effects), JavaScript (Async/Await, Fetch API, DOM manipulation)
- **Data Visualization**: Chart.js (CDN)
- **Icons & Typography**: Bootstrap Icons, Google Fonts (Outfit & Inter)

## 🚀 Quick Start Guide

### Step 1: Extract Project
Extract `personal_finance_tracker.zip` into your project directory.

```bash
cd personal_finance_tracker
```

### Step 2: Install Dependencies
Install Flask:

```bash
pip install -r requirements.txt
```

### Step 3: Run the Server
Start the web application:

```bash
python app.py
```

Open your browser and navigate to:
**`http://127.0.0.1:5000`**
